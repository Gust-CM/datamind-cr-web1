# DataMind CR - Desarrollo Web I

## Objetivo
Construir un sitio web académico de exactamente
3 páginas: Inicio, Galería y Contacto.

## Tecnologías
- HTML5 semántico
- CSS3 externo
- JavaScript nativo externo
- Sin frameworks, backend ni base de datos

## Reglas técnicas
- Mantener exactamente 3 archivos HTML.
- Utilizar rutas relativas.
- Reutilizar estilos CSS.
- Utilizar Flexbox o CSS Grid.
- Mantener diseño responsive.
- Utilizar nombres descriptivos.
- Escribir funciones pequeñas y comprensibles.
- Evitar código duplicado e innecesario.
- Comentar las partes principales del código.
- Implementar accesibilidad y navegación por teclado.
- No agregar dependencias sin justificación.

## Requisitos académicos
- Menú común en las tres páginas.
- Dos enlaces de ancla como mínimo por página.
- Galería con 10 imágenes, figure y figcaption.
- Galería con interacción y reinicio.
- Formulario con nombre, correo, asunto y mensaje.
- Validaciones JavaScript con errores descriptivos.
- Confirmación que indique que el envío es simulado.

## Forma de trabajar
- Proponer un plan antes de implementar cambios grandes.
- Trabajar una funcionalidad a la vez.
- Explicar qué hace el código y por qué.
- Indicar qué archivos se modifican.
- Enseñar los conceptos HTML, CSS y JavaScript usados.
- No crear commits ni hacer push sin autorización.
- No ejecutar acciones destructivas sin aprobación.
- Proponer comprobaciones y reportar sus resultados.
- No afirmar que algo funciona sin comprobarlo.

## Calidad
Priorizar simplicidad, mantenibilidad,
accesibilidad y cumplimiento de la rúbrica.
